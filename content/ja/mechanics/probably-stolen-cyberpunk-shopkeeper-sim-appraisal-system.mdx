## 鑑定システムが店の一日にどう組み込まれるか

Probably Stolenの鑑定は、クリックで飛ばせる任意のミニゲームではありません。すべての購入、すべての値交渉、すべての再販の前に立ちはだかる関門です。ゲーム自体の説明も率直です。サプライヤーは価値を誇張し、客は図々しく値を詰め、密輸品には取引を終えてから気づく問題が付いてくることもよくあります。

つまり、あなたの利益率は値札で決まるのではありません。目の前のカウンターに置かれたものをどれだけ正確に見極められるかで決まります。アイテムを読み違え、あるいは売り手を読み違えれば、損失は自分で抱え込むことになります。

| 鑑定ミス | 即時のコスト | その後のダメージ |
|---|---|---|
| 「レア」在庫にサプライヤーへ払い過ぎる | 現金の利益率が消える | 家賃の支払いが足りなくなる |
| 密輸品の隠れた欠陥を見逃す | 再販価値が崩壊する | 客の信頼が下がる |
| 偽物を本物として受け入れる | 偽物に正規価格を払う | 再販時に反発を招く |
| 自分の在庫を安く売り過ぎる | 1個あたりの利益を失う | 拡張とライセンス取得が遅れる |
| 武器の許可証確認を飛ばす | 在庫を没収される | 店への査察の目が厳しくなる |

パターンは一貫しています。悪い鑑定がその場であなたを殺すことはほとんどありません。しかし、次の家賃サイクルに必要な余裕を静かに削り取っていきます。

## アイテムを読む前に売り手を読む

コミュニティの報告は、利益を出し続けるプレイヤーに共通する習慣を一貫して指摘しています。彼らはまず人物を鑑定するのです。ゲーム内では、カウンターは未知の人物の行列として描かれます。証拠を探すセキュリティの密告者、 leverage を求める革命家、あなたが役に立つか試す没落したエリートたちです。

これらの類型はそれぞれ金銭の扱い方が違い、それぞれが異なる鑑定上の問題です。安値で商品をたたき売る神経質な売り手は、自動的に掘り出し物とは限りません。追跡の問題を抱えた盗品かもしれません。完璧な話をする口のうまい人物は、しばしば評価額を水増ししている側です。

| 売り手のタイプ | 典型的な兆候 | 賢い対応 |
|---|---|---|
| 追い詰められた運び屋 | 売却を急ぎ、目を合わせない | ペースを落とし、完全に検査し、強く交渉する |
| 口のうまい話し手 | 詳細な身の上話、曖昧な書類 | 数字に同意する前に出所を確認する |
| 没落したエリート | 見下す態度、すぐに立ち去りたがる | 丁寧に安値を提示する。比較検討はほとんどしない |
| セキュリティの密告者 | 価格ではなく在庫について尋ねる | 密輸品を見せず、中立を保つ |
| 同業の故買屋 | あなたの利益率をあなた以上に知っている | 現金ではなく物々交換にする |

プレイヤーの経験が示唆するのは、鑑定精度を上げる最も安上がりな改善策は、最初の提示額で買わないことだという点です。ゲーム内のほぼすべての売り手には交渉の余地があり、余地がない相手はたいてい、立ち去る価値のある相手です。

## 実践的なアイテム鑑定チェックリスト

すべての商品ラインが同じように失敗するわけではなく、鑑定システムもそれを反映しています。タバコのパックは再販前に目視検査が必要です。水は検査とろ過をしなければなりません。武器には許可証と適切な改造が求められます。利益の出る化学薬品は厳重に管理されたレシピに依存します。レア品は本物の鑑定が必要で、そうでなければ動かせないものに過剰な金額を払うことになります。

| アイテムカテゴリー | 必要な鑑定手順 | 警戒すべき危険信号 |
|---|---|---|
| タバコと消耗品 | パッケージの目視検査 | 再封・再印刷されたように見えるシール |
| 水 | 販売前の検査とろ過 | 濁り、容器の異様な重さ |
| 武器 | 許可証確認と改造レビュー | 書類の欠落、シリアル番号の不一致 |
| 化学薬品 | レシピと純度の検証 | 供給元を明かさないサプライヤー |
| レアなアーティファクトと部品 | 購入前の完全な鑑定 | 想定価格曲線から大きく外れた価格 |
| 盗品 | 出所と追跡リスクの評価 | 迅速で静かな取引を強く求める売り手 |

「An Eye for Value」の実績は、ここで良い心の目安になります。ゲームが求めているのは、固定価格表を暗記することではなく、もっとよく見るという反復可能な習慣を作ることです。価格は需給で変動しますが、検査手順は変わりません。

## 悪い鑑定を意図的な利益戦略に変える

ここが、Probably Stolen Cyberpunk Shopkeeper Simの鑑定システムが道徳的に興味深くなるポイントです。欠陥を見抜けるようになると、それを利用する選択もできるようになります。ゲームは、製品の品質を落とすこと、偽物を本物として再ラベルすること、セキュリティが自分に届かないと信じるなら割引された盗品を故買することさえ、明示的にサポートしています。

どれもただの金儲けではありません。それらは取引です。短期的な利益率と引き換えに、長期的なリスクを引き受けるのです。エリートは偽物によく金を払い、ほとんど細かく検査しません。しかし、検査する時が来ます。盗品は素早く動きます。しかし、襲撃や賄賂が利益を吹き飛ばす時が来ます。

| 戦術 | 利点 | 受け入れるリスク |
|---|---|---|
| 製品品質を落とす | 1個あたりの利益率が上がる | 常連客に気づかれると評判が傷つく |
| 偽物を本物として再ラベルする | 傲慢なエリートへ高値で売れる | 発覚時の派閥からの報復 |
| 盗品を故買する | 安い在庫、速い回転 | セキュリティの襲撃と没収 |
| 賄賂で逃れる | 当面の結果を回避できる | 継続的な現金流出と依存 |

正直な読み方はこうです。これらの道具は、家賃が苦しい週を乗り切るために使い、恒久的なビジネスモデルにはしないこと。コミュニティの報告によると、偽物に完全に傾倒したプレイヤーは、値上げで稼いだ以上に事後処理へ費やすことになります。

## 鑑定、派閥の警戒度、そしてオーグ問題

鑑定は真空の中で行われるわけではありません。評判はアクセスと保護をもたらしますが、同時にあなたの背中に標的を描きます。あらゆる販売は賭けです。承認する、断る、通報する、目をそらす。誰かが常に記録しています。

さらに、あなたにはステーション全体の政策を執行することが期待されています。自我を持つAIチップが暴走し、宿主を巻き込んでいなくなりました。強化された市民は、そうでなくなるまで他の人と同じに見えます。すべての派閥がこの政策に同意しており、銃を握っているのはあなたです。兆候を見逃すこと、あるいは読み違えることには、それ自体の代償があります。だからこそ、身体言語と行動の鑑定は、アイテムの鑑定と同じくらい価値があるのです。

| 警戒度の発生源 | どのように高まるか | 管理方法 |
|---|---|---|
| 許可証のない武器 | 在庫監査による査察の誘発 | 規模を拡大する前にライセンスを最新に保つ |
| むき出しの密輸品 | ピーク時間帯の襲撃リスク | 早い段階で隠し場所を作る |
| エリートへの偽物販売 | じわじわ蓄積する派閥の恨み | 買い手をローテーションし、品質を信じ込ませる |
| オーグの兆候を見逃す | 政策執行の罰則 | カウンターでのやり取りをゆっくり進める |

## 反復可能な鑑定ワークフロー

ほとんどの状況をカバーする1つのルーティンが欲しいなら、売り手が入ってくるたびにこの順序を使ってください。

1. **値付けの前に止まる。** まず売り手に話させる。最初の提示額で、その人がどれだけ売却を必要としているかがわかります。
2. **カテゴリーを特定する。** 武器、水、化学薬品、消耗品、レア品はそれぞれ異なる検査を要求します。
3. **必要なチェックを実行する。** 目視検査、検査とろ過、許可証レビュー、または完全な鑑定。アイテムに合った手順を決して飛ばさないでください。
4. **隠れた問題を探す。** 密輸品にはまだ気づいていない問題があると想定し、後で見つかる前提で値付けします。
5. **交渉前に撤退ラインを決める。** 値交渉は構いませんが、すべての取引にはトレードオフがあります。
6. **結果を記録する。** いくら払い、いくらで売り、何に驚いたかを追跡する。その記録が本当の鑑定スキルになります。

これを一貫して行えば、Probably Stolen Cyberpunk Shopkeeper Simの鑑定システムは予測可能になります。家賃が上がり続け、没収された在庫が1回のプレイを終わらせ得るゲームでは、まさにそれが望ましいのです。

## よくある質問

**Probably Stolenの鑑定システムはランダムですか？**
完全にランダムではありません。アイテムカテゴリーには定義された検査手順があり、水の検査、武器の許可証確認、レア品の鑑定などがリスクを減らします。ランダム性の大部分は、売り手があなたに隠していることにあります。だからこそ、注意深く検査し、守備的に値付けすることが重要なのです。

**新米店主として最初に何を鑑定すべきですか？**
完全に検査できる商品ラインから始めましょう。水と消耗品は寛容です。武器と化学薬品には査察や依存の結果が伴います。低リスクの商品でProbably Stolen Cyberpunk Shopkeeper Simの鑑定システムを学べば、序盤の家賃支払いを安全に保てます。

**意図的に悪い鑑定をして利益を出せますか？**
はい、ただし計算されたリスクとしてです。品質を落とすこと、偽物を再ラベルすること、盗品を故買することは、すべて利益率を上げ、すべて警戒度を上げます。緊急時の現金手段として扱い、恒久的な戦略にはしないでください。

**鑑定は派閥や評判に影響しますか？**
間接的に、しかし大きく影響します。ぼったくりのガラクタは客の信頼を損ない、エリートに売った偽物は敵を作り、オーグの兆候を見逃すことはステーションの政策に反します。Probably Stolenでは、正確な鑑定は値札をまとった評判管理なのです。
