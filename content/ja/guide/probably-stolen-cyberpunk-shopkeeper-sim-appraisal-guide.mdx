## 査定が店の存続を決める理由

**Probably Stolen - Cyberpunk Shopkeeper Sim** の家賃は、あなたの売店がどれほど魅力的に見えるかなどお構いなしに、決まったスケジュールで上がっていきます。そして最も早く落ちこぼれる道は、実際には一度も確認していない商品に定価を払ってしまうことです。繰り返し使える査定ルーティンがあるかどうかが、利益を複利で積み上げる店と、売れないガラクタの棚へ静かにクレジットを垂れ流す店とを分けます。この Probably Stolen サイバーパンク店主シム査定ガイドは、ひとつの考え方を軸にしています。すべての買い物を、まず評価の問題として扱い、交渉はその次に考えることです。

この捉え方が重要なのは、ゲームの設計そのものがあなたに逆らってくるからです。サプライヤーは商品の価値を水増しし、客はどこまで許されるかを試し、密輸品はクレジットが手を渡った後にしか表面化しない問題をしばしば隠しています。優れた Probably Stolen サイバーパンク店主シム査定ガイドは価格表を渡したりはしませんが、あらゆる取引で実行できるプロセスを渡してくれます。

本当の時計は家賃です。遅れれば店の魅力は下がり、入店する客は減り、売上は落ち、差は広がります。そしてキャッシュフローを安定させるためだけに、より危険な取引へと追い込まれます。序盤の一度のまずい査定は、商品そのものの価格よりはるかに高くつきます。

## 4ステップの査定ルーティン

サプライヤーがコートを開くたびに、同じ手順を実行してください。ゲーム内では数秒で済み、高くつく失敗の大半を防げます。

### 1. 価格の話をする前に検品する

商品を見る前に、売り手に数字でアンカリングさせてはいけません。たとえばタバコの箱は、転売前に目視確認が必要です。購入後に気づいた損傷は、あなたがかぶる損傷です。「いくら？」ではなく「見せてくれ」で切り出せば、交渉を自分の条件で進められます。

### 2. 消耗品はすべてテストし、フィルターにかける

水は棚に並べる前にテストと濾過が必須ですし、薬品はサプライヤーが主張するレシピではなく、自分が管理するレシピに依存します。下流の顧客を傷つけうるものはすべて、単なる交易品ではなく査定対象です。

### 3. 売り手の話ではなく、自分の棚を基準に値付けする

その商品が*自分の*カウンターから、*自分の*客に、現在の家賃サイクルの中で現実的にいくらで売れるのかを問いましょう。来歴の逸話や「あるコレクターはもっと高値を提示していた」といった話、需要に関する曖昧な語りはデータではありません。

### 4. 家賃を念頭に判断する

あなたの上限買取価格は、想定売価から家賃の分担分を引き、押収・検品失敗・単に動かない商品といったリスクのバッファを差し引いたものです。売り手がその数字を下回らないなら、その取引はすでに終わっています。

| 商品ライン | 確認すべきこと | 確認を省いたコスト |
|---|---|---|
| タバコと消耗品 | 転売前の目視状態 | 傷んだ在庫は安値でしか売れないか、断られる |
| 水 | テストと濾過 | 責任問題が利益だけでなく評判を直撃する |
| 武器 | 許可証と必要な改造 | 検品失敗、押収、罰金 |
| 薬品 | レシピの完全性と純度 | 依存症の余波、手入れ、派閥からの圧力 |
| 希少品・収集品 | 真贋と公正な市場価値 | 転売先のない偽物に過剰支払い |
| 盗品・密輸品 | セキュリティへの露出と隠し場所 | 手入れ、賄賂、闇市場での評判低下 |

## 各商品ラインが実際に求めるもの

開始時のアーキタイプによって、最も頼りにする査定スキルが決まります。ガンスミスは書類で生き死にし、フェンスは摘発の熱で生き死にします。どちらも同じチェックリストでは運用できません。

**ガンスミス。** 武器には検品がついてきます。すべての品に許可証が整っている必要があり、多くの場合、販売可能になる前に改造も必要です。利幅は大きいものの、失敗の形は残酷です。押収された出荷は一週間分を吹き飛ばしかねません。

**化学者。** 薬品は最高の利幅と最悪の隣人を連れてきます。レシピが厳重に管理されているのには理由があり、間違った客層にあまりに速く流れるロットは、金では逃げ切れない注目を集めます。

**水商人。** 最も安全な入口であり、最も薄い利幅です。テストと濾過は譲れません。水の下振れは押収ではなく責任問題だからです。

**フェンス。** 値引きされた盗品が安いのには理由があります。あなたはすべての品にセキュリティリスクを価格として織り込み、必要になる前に在庫を隠す場所を確保しておく必要があります。

**農家と臓器ディーラー。** 緩やかなカーブ、生産チェーン、機械コスト。ここでの査定は値引き交渉というより、投入物が機械時間に見合うかどうかの問題です。

**どん底スタート。** 何もない状態から始めるということは、最初の査定は小さく、家賃バッファはゼロだということです。退屈で検証可能な商品を買いましょう。

| アーキタイプ | 利幅の特性 | 査定の強度 | 主な脅威 |
|---|---|---|---|
| ガンスミス | 高い | 非常に高い | 検品と許可証の失敗 |
| 化学者 | 高い | 高い | 手入れと依存症の余波 |
| 水商人 | 低いが安定 | 中程度 | 責任追及 |
| フェンス | 変動が大きい | 中〜高 | セキュリティの注目 |
| 農家 | 遅いが安全 | 低い | 時間と機械コスト |
| どん底スタート | ごくわずか | 最初は低い | 家賃が成長を上回る |

ローンチ当初のコミュニティ報告によれば、序盤の破綻の多くは、店にクッションがないうちに高利幅の一品に過大投資することで起きています。プレイヤー体験は一貫して、最初の数家賃サイクルでは大きな一発勝負よりも、小さく検証済みの買い物を支持しています。

## 商品だけでなく、売り手を読む

査定の半分は品物です。もう半分はそれを手に持っている人物です。Probably Stolen の客やサプライヤーは中立ではありません。セキュリティの密告者、 leverage を探す革命家、あなたの有用性を試す落ちぶれたエリートが同じ扉を通って入ってきて、誰かが常に記録を取っています。

| カウンターでの兆候 | 通常の意味 | 最善の対応 |
|---|---|---|
| 市場価格よりはるかに安い | 盗品、欠陥品、または餌 | 完全検品するか断る |
| 検品を拒否する | 何かが隠されている | 立ち去る、カウンターオファーなし |
| 不自然な緊急性 | 圧力の手法 | 取引を遅らせ、再交渉する |
| 曖昧な来歴 | 偽造品または故買 | 具体的な説明を求め、オファーを下げる |
| バンドル提案 | 良い品が悪い品を隠している | 各品を個別に値付けする |

もう一層あります。暴走したAIチップと、それが制御するオーグメントです。あらゆる派閥がその方針で一致しており、銃を握っているのはあなたです。しかし兆候を読み違えれば、それ相応の代償があります。接客前に客の行動を査定することも、同じ規律の一部です。

## 査定の計算：利幅、家賃、撤退価格

クレジットのスライダーに触れる前に計算してください。シンプルな意思決定マトリクスが感情を排除します。

| 状況 | シグナル | 行動 |
|---|---|---|
| 検証済みの品、価格が撤退ライン以下 | クリーンな利幅 | 買う |
| 検証済みの品、価格がやや高い | 交渉可能な差 | 一度値切ってから再評価 |
| 検証不能な品、価格は問わず | 情報の欠落 | 断る |
| 検証済みの品、価格が撤退ライン超え | リスク後の利幅がマイナス | 立ち去る |
| 良い品だが隠せない | 露出が利益を上回る | 立ち去るか、賄賂予算を確保する |

さらに内在化しておくべき経験則が二つあります。第一に、次の家賃サイクルに必要なクレジットを一度の買い物で消費してはいけません。ゲームはそれを直接罰しますし、立て直しは安定させるためだけにより危険な取引を引き受けることを意味します。第二に、リスクを明示的に価格へ織り込みましょう。たとえば、検品に失敗する無視できない確率があるなら、その確率は願望ではなくオファーに含めるべきものです。

## 偽造、ラベル差し替え、それとも見送り？

ゲームは査定からより多くを絞り出す三つの方法を用意しています。製品の品質を落とす、偽造品を本物としてラベルを貼り替える、あるいはセキュリティが届かないと信じるなら値引きされた盗品を故買する。いずれも、群衆の正義システムが静かにしていることへの賭けです。

| 近道 | 利点 | 欠点 |
|---|---|---|
| 品質を落とす | 安い投入物、棚価格はほぼ同じ | 客が気づいたときの評判ダメージ |
| 偽造品のラベル差し替え | エリート客が本物価格を払う | 間違った客が確認すれば露見 |
| 盗品の故買 | 在庫を大幅値引きで確保 | 手入れ、賄賂、闇市場の打撃 |

正直な読み方はこうです。これらはすでに家賃のクッション、隠し場所、守る価値のある派閥関係を持つ店のための終盤ツールです。序盤では、勝っていたランを落とす方法になります。もし捕まっても、賄賂が逃げ道です。仕入れの予算を組むのと同じように、そのための予算を組みましょう。

公式の機能一覧、パッチノート、システム要件は [Steam の Probably Stolen - Cyberpunk Shopkeeper Sim](https://store.steampowered.com/) を確認してください。ストアページでは、ゲームの 17.99 ドルという価格、シングルプレイ、コントローラー対応、マウスのみでの操作オプションも確認できます。

## よくある質問

**レベル上げが必要なゲーム内査定スキルはありますか？**
Probably Stolen の査定は、単一のステータスではなく、ツール、ライセンス、情報によって動きます。アンロックしたものとカウンターで検証できるものを使って希少品を真贋判定するので、ライセンスと装備への投資が実質的に査定を改善する方法です。この Probably Stolen サイバーパンク店主シム査定ガイドは、ステータス表ではなくチェックリストとして使ってください。

**希少品で過剰に支払わない方法は？**
話す前に撤退価格を設定し、手持ちのツールで真贋を検証し、検証不能な主張は価値ゼロの主張として扱いましょう。希少品の価値は、現在の家賃サイクル内で自分の棚が実際に動かせる額だけです。

**サプライヤーが検品を拒否したらどうすればいいですか？**
断りましょう。このゲームでは拒否そのものが査定結果です。きれいな商品を持つ売り手が隠す理由はありませんし、見ずに買うことの下振れは完全にあなたに降りかかります。

**客を通報したり断ったりすると評判が下がりますか？**
下がることはありますが、選択的です。特定のキャラクターを通報することは、闇市場での立場を守るためにローンチ以降調整されています。また、販売を断るとわずかに好感度を失う代わりに露出を守れます。評判はアクセスと保護を買いますが、同時に的を描くことでもあるので、意図的に使いましょう。
